SISTEMA DE GESTÃO • ORG-LIMP

Sistema de Gestão de Limpeza

Sistema de gestão de atividades operacionais, desenvolvido a partir de um problema de planejamento, distribuição e acompanhamento de tarefas.

🎯 Problema de negócio

Dificuldade para planejar a semana, distribuir tarefas, acompanhar a execução e fornecer ao gestor uma visão confiável do andamento das atividades.

💡 Solução

Sistema com perfis de Gerente e Supervisor, plano semanal, tarefas, status, notificações, relatórios e configurações. permitindo que o Gerente planeje as atividades semanais e que o Supervisor acompanhe e atualize o andamento das tarefas em tempo real.

🔄 Processo modelado

01Planejar
02Distribuir
03Executar
04Atualizar
05Monitorar

Funcionalidades

  • Dashboard por perfil
  • Plano semanal
  • Cadastro e edição de tarefas
  • Filtros e paginação
  • Controle de usuários
  • Status das atividades
  • Notificações e relatórios
  • Configurações

Tecnologias

HTML5 • CSS3 • Bootstrap • JavaScript • LocalStorage • Java • Spring Boot • MySQL

O que demonstra

Análise de requisitos, modelagem de processos, regras de negócio, UX operacional e desenvolvimento de sistema responsivo.

💡 Evolução futura

A arquitetura pode evoluir de LocalStorage para API REST com Java/Spring Boot, autenticação, banco MySQL e integrações corporativas.
